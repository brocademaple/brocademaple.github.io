## 第一次打开：认识四块常用区域

中央 3D Viewport 用来查看与操作物体；右上 Outliner 列出对象和 Collection；右侧 Properties 控制材质、修改器、渲染等设置；底部 Timeline 存放帧与相机切换标记。

在 Outliner 找到 `02_V2_GLASS_GALLERY`、`03_V2_GRAND_TIDE_ARCHIVE` 和 `09_V23_CURATED_WORKS`。Collection 是分组容器，Object 是具体对象，Mesh 是顶点和面构成的数据。相同 Mesh 数据可被多个 Object 共用，修改几何时可能影响所有共享对象。

检查点：你能在 Outliner 点选一件物体，并看到它在视口中高亮；在 Properties 找到它的材质。临时隔离可用 Local View，恢复后确认其他集合没有被误删。

## 先会看，再动模型

默认鼠标操作：中键拖动旋转视角，Shift＋中键拖动平移，滚轮缩放。数字键盘 0 查看当前相机；数字键盘小数点聚焦选中对象；数字键盘 1、3、7 分别看前、侧、顶。菜单 View → Cameras → Active Camera 和 View → Frame Selected 可代替数字键盘。

MacBook 没有数字键盘时，优先用 View 菜单和右上方向导航控件。Preferences → Input → Emulate Numpad 可把上排数字键映射为数字键盘，但会改变这些键在编辑模式中的原有用途。鼠标与触控板替代操作见 [Blender 外设配置](https://docs.blender.org/manual/id/4.5/getting_started/configuration/hardware.html)。

本工程时间线 1、21、41、61、81、101、121、141 帧分别绑定新月园区、园区全貌、花园环路、玻璃长廊、潮汐档案、上层回廊、下层典藏、材质亭。将当前帧改为 61，再进入相机视图，应能看到玻璃长廊。这里的帧号用于机位审阅，不意味着有完整动画。

检查点：依次观察园区、玻璃长廊、档案馆，说明入口、环路和楼层之间的关系。找不到物体时先 Frame Selected，再检查集合可见性与相机方向。

## 物体模式与编辑模式：一次只解决一个问题

Object Mode 移动整个物体；Tab 切换到 Edit Mode 后，修改顶点、边或面。G 移动、R 旋转、S 缩放；随后输入 X/Y/Z 可限制坐标轴，再输入数字获得精确量值。Enter 确认，Esc 取消。

在学习副本里选择一根柱子，Shift＋D 复制，输入 X、2、Enter，得到水平相距 2 米的副本。给副本改名 `LAB_Column`。N 面板的 Item 区域显示位置、旋转、缩放与尺寸。完成后检查原柱的位置没有改变。

要练结构，先加 Cube 做地板与展墙，再加 Cylinder 做柱子。最初只关心尺度、门洞和通路，保留足够站立与行走空间。项目先做灰盒、再做壳体与生态，正是为了先验证空间结构。

## 尺度、倒角与法线：建筑为何看起来成立

Scene Properties → Units 使用 Metric。建模时把地板厚度、柱高、门宽明确成米。缩放后的物体可在 Object Mode 使用 Object → Apply → Scale，使 Scale 回到 1；在学习副本中操作，尤其不要随意应用相机、灯光或带动画的变换。

Bevel 修改器给硬边很小的倒角，侧光才能在边缘形成可见高光。一个 3 米高的柱子可以先尝试 0.02–0.04 米倒角，观察近景后决定，避免用同一数值处理所有尺度。Shade Smooth 改善曲面外观，不会增加几何细节。

法线决定面朝向。Overlay → Face Orientation 可检查正反面；在编辑模式选中几何，再 Mesh → Normals → Recalculate Outside。项目 V2.4 曾修正通路朝内的法线，避免路面着色与支撑面判定异常。封闭实体、薄玻璃和双面展板要分别判断，不能对全部对象盲目重算法线。

检查点：复制柱子的边缘出现自然高光；地板没有因为反面导致消失。若想把复杂修改器结果导出，需要检查导出是否应用修改器，并核对实际三角面数。

## 材质：从白模走到石材、青铜与玻璃

Material 是表面如何响应光线的规则；Texture 是表面的图像或数值输入。Shading 工作区里，Principled BSDF 提供基础颜色、粗糙度、金属度等常用参数，接到 Material Output 的 Surface。

先给练习展墙加材质：Base Color 用偏暖石色，Roughness 约 0.65，Metallic 为 0。给画框换材质：偏暗青铜色、Metallic 约 0.75、Roughness 约 0.35。参数是练习起点，需要根据灯光和实际参考调整。

项目中 `V24_HonedTravertine` 用于细石材，`V24_CoursedTravertine` 带砌块结构，`V24_OpusPaving` 用于镶嵌铺地，`V24_GardenPebbles` 用于花园碎石。这四组都有 Base Color、Normal 和 ORM 数据。ORM 将遮蔽、粗糙度、金属度放在 R、G、B 通道，减少贴图数量。

Base Color 是颜色，常用 sRGB；Normal、Roughness、Metallic、ORM 是数据，应使用 Non-Color。Normal 贴图先接 Normal Map 节点，再接 BSDF 的 Normal。材质灰白时，先查贴图是否加载、节点是否接对，再查灯光与曝光。相关规则见 [色彩管理手册](https://docs.blender.org/manual/uk/4.5/render/color_management.html)。

## UV 与作品挂墙：让图像保持原本比例

UV 是把三维表面展开到二维图片的坐标。给一个 Plane 挂作品时，先按图片宽高比设置尺寸。例如 1200×800 图片，若展板高 1.2 米，则宽 1.8 米。不要把所有画作都拉成同一长方形。

练习：在副本新增 Plane，旋转到展墙方向，设宽 1.8 米、高 1.2 米，在 Shading 加 Image Texture，打开一张你已有的横幅图片，接 Base Color。Edit Mode 全选平面，在 UV Editing 检查四个角覆盖图片边界。观察画中圆形有没有被拉成椭圆。

项目以 `gallery_artwork_thumb` 等 Custom Properties 保存作品身份，网页按身份找到目录与详情。42 件作品已检查原始 JPEG 字节、实际几何宽高比和 UV。不要靠文件名排序或数组切片决定墙上挂哪张图。

检查点：图片方向正确、比例不变、没有贴在墙内；浏览器点击后打开的标题、原图与当前墙画一致。

## 灯光与相机：把好模型变成可读画面

材质预览使用预览环境；Rendered 使用实际场景的灯光、世界与渲染设置。两者观感不同，最终检查应使用 Rendered 或 F12 渲染。F12 渲染当前相机；Render → Render Image 可代替快捷键。

先用一个大 Area Light 照亮练习展墙，它的尺寸越大，阴影通常越柔和；再以较弱补光改善暗部。能量、尺寸、距离与材质要一起判断。项目使用海面冷光、海床补光和展厅暖光，使建筑从水下环境中分离。

相机焦距影响空间感。短焦距能包含更多场景，也会夸大近大远小；长焦距压缩空间。项目 `V23_heroCamera` 为 40 mm，`V23_glassCamera` 为 25 mm。比较镜头时必须同时记录位置、朝向、画幅比例与视场角。

检查点：展墙、画框、门洞都能读清；灯光不把石色冲成纯白；相机没有进入墙体。项目 V1 出现的“十字形装置”其实由栏杆、楼梯与穹顶肋条在错误视角下叠加，修复相机就能解决，无须删除有效结构。

## 渲染与色彩管理：怎样判断画质

本工程使用 Eevee Next、AgX、Medium High Contrast，曝光约 +0.3。本次四张 1400×900 图片使用 128 samples，来自当前 V2.4 源文件。Eevee 适合快速审阅；Cycles 用路径追踪计算光线，质量与耗时取决于采样、去噪、场景和设备。

先用较低分辨率检查构图、颜色与遮挡，通过后再提高采样。加采样主要减少噪点，不能修好错误的材质、机位或结构。玻璃、世界光和合成效果也可能在导出到网页后改变。

保存渲染图时记录版本、机位、引擎、分辨率与采样。不要拿概念图作为模型完成证据，也不要把不同机位的图片称为同机位对比。

## 从 Blender 到网页：保留什么、需要重建什么

常用导出为 File → Export → glTF 2.0，格式选择 GLB。GLB 可包含网格、PBR 图像材质、UV、相机、部分灯光与自定义属性。它不能自动复制任意 Blender 节点、世界灯光、Area Light 或完整合成流程。官方说明见 [glTF 导出手册](https://docs.blender.org/manual/sv/4.5/addons/import_export/scene_gltf2.html)。

因此应把程序化表面转为可携带的贴图，检查 UV，使用可识别的 Principled 材质通道。自定义属性需要随导出保存。本项目在 glTF extras 中保留作品和导航信息，网页从模型读取，减少两套坐标漂移。

项目网页使用 Three.js，在网页重建水下背景、环境反射、阴影与动态水光。高清和流畅读取同一份 GLB；高清增加像素比例、阴影尺寸与水光动画。Meshopt 压缩保留面数；新 PBR 的无损 WebP 压缩经解码像素比较通过；42 件作品 JPEG 保留原字节。

网页与源模型已经做到几何和作品数据一致。实时玻璃折射、间接照明、阴影柔度与 Blender 的画面仍存在差异。云服务器会影响加载与稳定性，改变服务器无法自动修复客户端渲染差异。固定机位的原始 Blender PNG 可在线原样呈现；自由步行需要浏览器实时渲染。
